## Ein unabhängiger Community-Leitfaden

GHE Launchpad bündelt die offizielle Dokumentation von GitHub und Microsoft für ein wiederkehrendes Setup zu einem geordneten Weg: GitHub Enterprise Cloud mit Datenresidenz, Enterprise Managed Users mit Microsoft Entra ID, Abrechnung über Azure und GitHub Copilot.

<Callout type="caution" title="Keine offizielle Dokumentation">
Dieser Leitfaden ist keine offizielle Dokumentation von GitHub oder Microsoft. Produkte ändern sich, und maßgeblich ist immer die offizielle Dokumentation. Jeder Schritt verlinkt die Seiten, auf denen er beruht.
</Callout>

## Wie der Leitfaden aktuell bleibt

- Jede Seite zeigt unten an, wann sie zuletzt mit der offiziellen Dokumentation abgeglichen wurde.
- Links auf externe Seiten werden jede Woche automatisch geprüft.
- Ist Ihnen etwas Veraltetes aufgefallen? [Eröffnen Sie ein Issue](https://github.com/edinc/ghe-launchpad/issues) oder nutzen Sie **Seite bearbeiten** unten auf jeder Seite.

## Datenschutz

- Diese Website setzt keine Cookies und nutzt weder Webanalyse noch Tracking. Sie ist eine statische Website auf GitHub Pages; GitHub [protokolliert dabei aus Sicherheitsgründen die IP-Adressen der Besucher](https://docs.github.com/de/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).
- Schriften werden von dieser Website ausgeliefert, nicht von einem Schriftendienst.
- Videos werden erst dann von YouTube (youtube-nocookie.com) geladen, wenn Sie sie abspielen. Ab diesem Moment erhält YouTube Daten wie Ihre IP-Adresse.
