## An independent community guide

GHE Launchpad puts the official GitHub and Microsoft documentation for a recurring setup into one ordered route: GitHub Enterprise Cloud with data residency, Enterprise Managed Users with Microsoft Entra ID, billing through Azure, and GitHub Copilot.

<Callout type="caution" title="Not official documentation">
This guide isn’t official GitHub or Microsoft documentation. Products change, and the official documentation is always the source of truth. Every step links to the pages it’s based on.
</Callout>

## How it stays current

- Each page shows at the bottom when it was last checked against the official documentation.
- Every week, an [AI agent](https://github.com/edinc/ghe-launchpad/blob/main/.github/workflows/docs-check.md) (GitHub Copilot) compares the guide with the official documentation it links to. When something no longer matches, it opens an issue, and a maintainer reviews and fixes it.
- Links to external pages are checked automatically every week.
- Spotted something outdated? [Open an issue](https://github.com/edinc/ghe-launchpad/issues) or use **Edit page** at the bottom of any page.

## Your privacy

- This site sets no cookies and uses no analytics or tracking. It’s a static site on GitHub Pages, which [logs visitors’ IP addresses for security purposes](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).
- Fonts are served from this site, not from a font service.
- Videos load from YouTube (youtube-nocookie.com) only after you press play. From then on, YouTube receives data such as your IP address.
