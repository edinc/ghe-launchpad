# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately through GitHub instead: **[Report a vulnerability](https://github.com/edinc/ghe-launchpad/security/advisories/new)** (repository → Security → Advisories).

Include what you found, where (page, file or workflow) and how to reproduce it. You'll get an answer within a few days; this is a community project maintained in spare time.

## Scope

In scope: the published site at https://edinc.github.io/ghe-launchpad/, this repository's code and its GitHub Actions workflows.

Out of scope: GitHub and Microsoft products themselves. Report those to the [GitHub Security Bug Bounty](https://bounty.github.com) or the [Microsoft Security Response Center](https://msrc.microsoft.com).

## Supported versions

Only the current `main` branch, which is what the live site serves.
